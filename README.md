
# 🌾 AgroVision – SIH 2025

AgroVision is an **AI-powered agriculture advisory application** developed for **Smart India Hackathon 2025**. The project helps farmers with **real-time mandi prices** and **image-based crop guidance** using AI.

## 🚀 Features

* 📈 Real-time **mandi (market) price tracking**
* 🤖 **AI crop advisory** via image uploads
* 🌱 Crop care instructions and insights
* 📱 Farmer-friendly interface
* 🧠 Data-driven decision support

---

## 🎯 Problem Solved

Farmers often lack access to scientific guidance and fair market prices, leading to poor decisions and income loss. AgroVision provides easy access to reliable, data-driven advice and market data to improve productivity and profitability.
